Import Guide

Learn how to prepare and import your data

If your Excel has multiple sheets or title rows:

  1. Multiple sheets: Enter the exact sheet name (e.g., "Bank Statements", "Sheet1")
  2. Title rows: If your file has a title row before headers, set "Skip rows" to the number of rows to skip
  3. Example: If row 1 has "DTI System Report" and row 2 has headers, set "Skip rows" to 1

Required columns:

  • supplier - Supplier name

Optional columns:

  • tin - Tax ID (###-###-###-###)
  • vat_status - VAT status: NV, V, NA
  • philgeps_registration - PhilGEPS code
  • address - Business address
  • propprietor - Owner name
  • contact_number - Phone number

Required columns:

  • date - Transaction date (YYYY-MM-DD)
  • description - Transaction description
  • balance - Account balance

Optional columns:

  • check_number - Check/Reference number
  • debit - Money going out
  • credit - Money coming in
  • status - Status: Cleared, On Process
Note: Only ONE of debit or credit per row. Both cannot be > 0.
